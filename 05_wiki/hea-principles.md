# HEA 原点と 4大コア効果

## 定義 (憲章)
- n≥5 主元素, 5≤c_i≤35 at%, ΔS_mix = -R Σ c_i ln c_i ≥ 1.5R (目標 1.61R)
- 単相固溶体 (BCC または BCC/B2 ナノ整合): Ω≥1.1, δ≤6.6%, VEC<6.87

## 4大コア効果
1. **高エントロピー効果**: 固溶相の自由エネルギー極小化 → 単相安定化
2. **深刻な格子歪み**: 原子半径差 → 転位運動抵抗 → 比剛性・降伏強度向上
3. **遅延拡散**: 相分離・粒成長抑制 → 緻密安定組織
4. **カクテル効果**: 複合不動態皮膜 (TiO₂/Cr₂O₃/Al₂O₃/ZrO₂/...) 自発形成

## 相安定性
粗大 σ相・ラーベス相排除。ナノスケール整合析出 (B2/Heusler) のみ許容。
