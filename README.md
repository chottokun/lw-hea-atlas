## 💡 軽量高エントロピー合金（LW-HEA）とは？

**高エントロピー合金（High-Entropy Alloys, HEA）** は、従来の「1つの主要元素に微量添加する」合金設計とは根本的に異なり、5種類以上の主要元素が等比率近くで混ざり合うことで、高い配置エントロピー効果により単相固溶体を安定化させ、優れた強度・耐熱性・耐食性を示す次世代の構造材料群です。

しかし、従来の代表的HEA（Cantor合金 `CoCrFeMnNi` や難溶性耐熱HEA `NbMoTaW` 等）は高密度な遷移金属を主成分とするため、密度が **6.0 〜 12.0 g/cm³** と重く、航空宇宙、自動車、エネルギー機器、先端ロボティクスが切望する「軽量化」の要請に応えられないという構造的限界がありました。

これに対し、**軽量高エントロピー合金（Light-Weight High-Entropy Alloys, LW-HEA）** は、Al（アルミニウム）や Ti（チタン）などの軽量元素を巧みに骨格とし、**純チタン（4.51 g/cm³）以下の超軽量でありながら、チタン合金を上回る高剛性（E/ρ > 25 GPa·g⁻¹cm³）と、海洋塩化物環境下での超高耐食性を同時に達成しようとするフロンティア材料領域**です。

### なぜ自律型AIと材料インフォマティクスによる「実験的試み」について
軽元素（Al, Si）と早期遷移金属（Ti, V, Cr, Nb等）の多元素共存系は、混合エンタルピーが負に大きく、結晶粒界に**脆性金属間化合物（Laves相や脆性シリサイド）**が析出しやすいほか、元素間の電位差による**微小ガルバニック腐食**が急速に進行しやすいという熱力学・物理化学的な背反（トレードオフ）を抱えています。

そこで、材料科学者が生成AIを利用するイメージでトライしてみました。つまり、個人的で利用できるAIエージェントという制約の範囲で、**自律型AIエージェントと計算材料インフォマティクス（MI）の簡単な物理評価エンジンを融合して、有意義な参考情報が掘り起こせるか？**という取り組みです。その結果、思いのほか興味深い提案をも得ることができました。もちろん、材料科学では、現実に製造できるか、様々な安全性が確保されるか、といった現実的制約が大きく、さらにスケールファクターまで睨んだ開発が重要です。今回の検討は、小規模な個人的な机上検討ですが、お手軽にまとめることができることができました。さらに、様々な計算も出るとの結合ができれば面白いことになるのでしょう。

## 🎯 探索目標 (Mission & Charter)

* **Mission**: 超高耐食性（**log₁₀(I_corr) ≤ -7.0 A/cm²** in 3.5 wt% NaCl）× 軽量（**ρ ≤ 4.50 g/cm³**）× 高比剛性（**E/ρ > 25 GPa·g⁻¹cm³**）を同時達成するパレート最適組成の同定と、机上未踏可能性マップの体系化。
* **Charter (相選択制約)**: 主元素数 **n ≥ 5**, 各元素濃度 **5.0 ≤ c_i ≤ 35.0 at%**, 混合エントロピー **ΔS_mix ≥ 1.5R**, 原子寸法差 **δ ≤ 6.6%**, 相安定性 **Ω ≥ 1.1**（または B2 整合ナノ析出許容領域）, 価電子濃度 **VEC < 6.87**, 単相 BCC / BCC+規則 B2 ナノ整合組織。

## 🎛️ 境界緩和シナリオ（If-Then Boundary Relaxation Study）

机上探索により、「初期の厳格制約をわずか数％緩和することで開花する広大な材料空間」を定量化：

* **Scenario A: 密度上限の緩和（ρ ≤ 4.50 → 4.65 g/cm³）**
  - **解禁効果**: 第2不可能性定理（Si/Scフリーでは ρ ≤ 4.50 不可）を回避し、**Si/Scフリーの「純バルブメタル系（`Al-Ti-V-Cr-Nb-Zr`）」が一気に 505 件解禁**。
  - **代表解**: `Al35 Ti35 V10 Cr10 Nb5 Zr5`（ρ = 4.53 g/cm³, δ = 5.42%, silicide_risk = 0, logI = -7.73）。シリサイド脆化リスクゼロの高信頼性構造材料。
* **Scenario B: 第6元素の微量添加許容（c_Si = 2.0 〜 3.5 at%）**
  - **解禁効果**: Si 5 at% 強制による格子歪み（δ ≈ 6.5〜6.7%）が緩和され、**δ < 6.0% の Nb/Mo フリー高均質系（`Al-Ti-V-Cr-Mn-Si`）が 3,110 件解禁**。
  - **代表解**: `Al34 Ti35 V14 Cr7 Mn7.5 Si2.5`（ρ = 4.48, δ = 5.85%, σ_Tm = 482 K）。シリサイド析出が半減し、製造性が飛躍。
* **Scenario C: 主元素上限緩和（c_i ≤ 40 at%）**: 中・高エントロピー境界領域（ΔS ≥ 1.45R）での Ti/Al 富化設計。
* **Scenario D: 急冷凝固・積層造形（AM / LPBF / スパッタ薄膜）**: 平衡固溶限を突破した極限高剛性・高硬度領域。

## 🔬 核心的物理・化学メカニズム（設計原理と理論的知見）

1. **6元系の数学的必然性（第1不可能性定理）**:
   5元系 `Al-Ti-V-Cr-Nb`（各元素 5〜35 at%）では ρ ≤ 4.50 g/cm³ と ΔS ≥ 1.5R の同時達成が不可能。密度のみを最小化すると ρ = 4.458 g/cm³（Al35 Ti35 V20 Cr5 Nb5）が得られるが、組成の偏りにより ΔS_mix ≤ 1.403R に留まる。高エントロピー条件（≥ 1.50R）を満たす領域では重元素比率が増加し ρ ≥ 4.62 g/cm³ に達するため、Si 5 at%（ρ = 2.33）または Sc の導入による 6元系化が数学的・熱力学的に必須。
2. **純遷移金属＋Al 6元系の密度限界（第2不可能性定理）**:
   Si/Sc を含まない純バルブメタル系（`Al-Ti-V-Cr-Nb-Zr`）は、最軽量組成でも ρ_min = 4.532 > 4.50 g/cm³ となり 100% 棄却。Track A では Al, Ti に次ぐ「第3の軽量元素（Si または Sc）」の導入が数学的絶対条件。
3. **Ti の結晶学的サイズ緩衝作用（Atomic-size buffer）**:
   Ti（原子半径 r = 1.47 Å）を抜くと剛性は落ちず、原子寸法差が δ = 8.1〜11.2% に爆発して BCC 格子が崩壊。Ti は大半径元素（Al, Sc）と小半径元素（Cr, V, Si）を仲介する不可欠のサイズバッファ。
4. **点欠陥モデル（Point Defect Model, PDM）による半導体欠陥補償**:
   Al 高濃度化（30 at% 以上）に伴い不動態皮膜中で急増する n 型ドナー欠陥（酸素空孔 V_O••）を、p 型 Cr₂O₃、高絶縁性 TiO₂、および非晶質 SiO₂ の五元複合化で電気化学的に補償（SDCI = 1.67 ≥ 1.5）。
5. **文献ベンチマークによるキャリブレーションと予測仮説**:
   文献実測値 AlCrTiV_0.5（I_corr = 0.131 µA/cm² ⇒ log₁₀(I_corr) = -6.883 in 3.5 wt% NaCl, [Materials 2023](https://doi.org/10.3390/ma16072922)）をアンカーとして偏析・エントロピー補正モデルを単点適合。本命 A1（モデル予測値 logI = -7.90）はこの基準値を超える耐食性を示す予測仮説となっており、今後の湿式電気化学試験による検証対象。
6. **Mo ドープによる MoO₄²⁻ 吸着再不動態化**:
   A-Mo 合金では Mo 5 at% 配合により PREN が 38.0 → 47.0 へ急増。ピット内部へのモリブデン酸アニオン吸着が Cl⁻ を競合排除。
